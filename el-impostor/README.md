# El Impostor (POO - Python)

Juego de deducción hecho con POO, SOLID y MVC.

## Carpetas
- `modelo/`: clases del juego (rol.py, jugador.py, partida.py)
- `servicios/`: validadores de pistas, asignador de roles y contador de votos
- `tests/`: pruebas unitarias
- `docs/`: diagrama UML

(La vista y el controlador se agregan en la Entrega 3.)

## Probar
```
python -m unittest discover tests
```
